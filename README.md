# sanchuan-app

三川工方工程管理系統。

## 施工前後模擬（`simulator.html`）

單一檔案、免安裝，用瀏覽器直接開啟即可使用。上傳工地現況照片，在照片上塗抹要更換材質的範圍，再上傳木皮／材質色板，由 Google Gemini 生成模擬圖並提供前後對比。

### 使用步驟

1. 開啟 `simulator.html`，點右上角「設定金鑰」貼上 Google Gemini API 金鑰
   （到 [aistudio.google.com/apikey](https://aistudio.google.com/apikey) 免費申請）。
   金鑰只存在瀏覽器的 localStorage，不會上傳到任何伺服器。
2. **上傳現況照片** — 建議正對牆面拍攝、光線平均。
3. **圈選要模擬的範圍**

   **模擬條件（顏色）** — 一個顏色代表一種材質，可以同時做好幾種。
   例如洋紅圈牆面配微水泥、青色圈櫃體配深胡桃木，一次生成。
   按「＋ 新增條件」增加顏色，第二步選的材質會套用到目前選取的那個顏色。

   **AI 自動框選** — 輸入或點選部位（牆面／地板／天花板／櫃體／門片／
   檯面／窗框／踢腳板），AI 會分出貼合輪廓的邊界，多片門片會分開列出。
   點畫面上的色塊或清單可逐一開關，確認後按「套用」。

   **手動工具**

   | 工具 | 用法 |
   | --- | --- |
   | 👆 點選 | 點畫面上的物件，AI 自動抓它的邊界；再點一次取消 |
   | 🖌 塗抹 | 手指直接塗，適合不規則形狀 |
   | 📏 直線 | 拖曳畫粗線，粗細用滑桿調 |
   | ▭ 方框 | 斜拉框選一整塊 |
   | ◯ 圓形 | 斜拉圈選橢圓範圍 |
   | 🧽 擦除 | 把多選到的部分擦掉 |

   另有復原、清除此色、全選、換照片。
4. **選擇想要的材質**（套用到目前選取的顏色）— 材質、文字、色板，至少給一項：
   - 材質分類：淺色木紋／深色木紋／仿石紋／微水泥／清水模／膚感／金屬感。
     點分類後直接顯示對應色票與名稱，點一下即選取（再點一次取消）。
   - 補充需求（選填）：直接打字，例「顏色再淺一階、木紋要垂直走向」。
   - 實際色板照片（選填，最準）：AI 會直接抓它的顏色與紋理。
   - 指定部位（選填）：例「電視牆造型木作」，講越清楚越準。
     完全沒有圈選時，改由這一欄指定要改哪裡，但此時無法鎖定其他區域。
5. **開始模擬** — 完成後「模擬圖」分頁直接顯示生成結果，
   切到「前後對比」可拖曳滑桿比較施工前後，並可下載模擬圖。

### 模型選擇

| 選項 | 模型 ID | 說明 |
| --- | --- | --- |
| Nano Banana Pro | `gemini-3-pro-image-preview` | 畫質最好，單價較高 |
| Nano Banana 2 | `gemini-3.1-flash-image-preview` | 預設，速度快、成本低 |
| Nano Banana | `gemini-2.5-flash-image` | 舊版 |

### 「鎖定未選取區域」

預設開啟。開啟時只會把 AI 產生的像素套用在塗抹範圍內（邊緣做羽化銜接），
範圍以外的畫面直接沿用原照片，確保牆面、地板、家具不會被模型順手改掉。
關閉則直接使用 AI 的完整輸出。
