# sanchuan-app

三川工方工程管理系統。

## 施工模擬（`simulator.html`）

單一檔案、免安裝，手機瀏覽器直接開。用法跟平常傳照片給 AI 一樣。

線上版本：<https://heaven2935-code.github.io/sanchuan-app/simulator.html>

### 怎麼用

1. 右上角「金鑰」貼上 Google Gemini API 金鑰
   （[aistudio.google.com/apikey](https://aistudio.google.com/apikey) 申請，貼上後按「測試」確認）。
   金鑰只存在這台裝置的瀏覽器。
2. 按 **＋** 加照片，一次可以加多張（現況照、色板照、型錄照），
   縮圖上會標「圖1」「圖2」。
3. 打一句話送出，可以直接用編號指涉，例：

   - 這座衣櫃的外觀顏色改成圖2的深灰
   - 模擬成這張清水模的照片
   - 顏色再深一階，壓條改成玫瑰金

4. 結果出來後可以**接著講**，它記得前面的對話。

### 要精準指定範圍時

點附件縮圖，或結果卡上的「✏️ 標記再改」，進到標記畫面用手指塗要改的地方，
按完成後那張圖會帶著標記送出，AI 只改塗到的部分。

### 其他

- **接著改這張**：把某張結果放回輸入區當底圖。
- **分享**：走系統分享，可直接送到 LINE；不支援時改為下載。
- 模型不寫死型號：向 API 查詢這把金鑰可用的影像模型並自動挑選，
  型號被下架時會自動重挑。

### 需要開啟計費

Gemini 影像模型的免費額度為 0，需要在金鑰所屬的 Google Cloud 專案開啟計費。
一張約 NT$1～4，依模型而定。
