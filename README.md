# sanchuan-app

三川工方工程管理系統。

## 施工前後模擬（`simulator.html`）

單一檔案、免安裝，用瀏覽器直接開啟即可使用。
上傳工地現況照片後，直接用一句話說要怎麼改，AI 會自己找出範圍並生成模擬圖。

線上版本：<https://heaven2935-code.github.io/sanchuan-app/simulator.html>

### 使用步驟

1. 點右上角「金鑰」貼上 Google Gemini API 金鑰
   （到 [aistudio.google.com/apikey](https://aistudio.google.com/apikey) 申請，
   貼上後可按「測試金鑰」確認）。金鑰只存在瀏覽器的 localStorage，不會上傳。
2. **上傳現況照片** — 建議正對牆面拍攝、光線平均。
3. **打一句話** — 例「把系統櫃門片換成深胡桃木」。
   AI 會理解需求並框出範圍，畫面上顯示金色供確認。
4. **確認範圍** — 框錯的可以點標籤或畫面上的色塊個別關掉，
   再按「對，開始模擬」。完全不對就按「不對，我自己圈」。
5. **繼續講** — 結果會成為新的底圖，可以接著說「顏色再深一點」、
   「地板換成淺橡木」逐步疊加。點對話紀錄的縮圖可回到任一版。

畫面預設只有三樣東西：**照片、輸入框、模擬結果**。
其餘功能收在右下角的圓點裡，點一下展開：客戶模式、分享全部、
前後對比、色板庫、配色建議、自己圈範圍、回到原圖、金鑰與畫質。

### 建材行電子型錄

色板庫的「建材行型錄」分頁可以存自己的建材行清單（名稱 + 電子型錄網址），
單筆新增或「貼上整份清單」一次匯入（每行「名稱 空格或逗號 網址」）。
清單存在瀏覽器 localStorage。

取用型錄上的顏色：

1. 點「開啟型錄」（開新分頁）
2. 在型錄上長按要的顏色 → 拷貝
3. 回到工具按「📋 從剪貼簿貼上」，圖直接進色板庫

> 受瀏覽器同源政策限制，網頁無法直接讀取其他網站上的圖片，
> 因此無法做到在型錄上點一下就自動匯入；上面的拷貝／貼上是可行的最短路徑。
> 桌機也可以直接在頁面上按 Ctrl/Cmd+V。

### 客戶模式與分享

按圓點 →「客戶模式」進入全螢幕，左右滑動或點箭頭切換原圖與各方案。
畫面下方大字標出這一張用的是哪個色板（縮圖 + 名稱 + 當初的指令），
相近的顏色也分得出來，可以直接把手機遞給業主看。

分享一律走系統分享，可以直接送到 LINE：
- 單張：結果卡片上的「📤 分享」，或客戶模式裡的「分享」
- 全部：圓點 →「分享全部」，一次送出所有方案

分享與下載的圖片下緣都會燒上色板縮圖與材質名稱，
業主收到檔案時不會分不出哪張是哪個色號。
瀏覽器若不支援系統分享會自動改為下載。

### 進階：自己圈選範圍

AI 框不準時，展開底部的「⚙ 進階」自己圈：

| 工具 | 用法 |
| --- | --- |
| 👆 點選 | 點畫面上的物件，AI 自動抓它的邊界 |
| 🖌 塗抹 | 手指直接塗，適合不規則形狀 |
| ▭ 方框 | 斜拉框選一整塊 |
| ◯ 圓形 | 斜拉圈選橢圓範圍 |
| 📏 直線 | 拖曳畫粗線，粗細用滑桿調 |
| 🧽 擦除 | 把多選到的部分擦掉 |

自己圈好之後，下面直接打「換成 XXX」就只會改這一塊，不會再問你確認。

進階面板裡的材質色票（淺色木紋／深色木紋／仿石紋／微水泥／清水模／
膚感／金屬感）點一下會把完整材質描述帶進輸入框，可以再自己加字。

### 未選取範圍的保護

有圈選範圍時，AI 產生的像素只會套用在範圍內（邊緣做羽化銜接），
範圍以外直接沿用原本的畫面，確保牆面、地板、家具不會被順手改掉。
若 AI 找不到明確範圍而由它自行判斷，就沒有這層保護，畫面上會提醒。

### 模型選擇

右上角可切換：**快速**（`gemini-3.1-flash-image-preview`，一張約 NT$1）
與 **Pro**（`gemini-3-pro-image-preview`，畫質最好，一張約 NT$4）。
辨識範圍另外使用 `gemini-2.5-flash`，成本低很多。

需要在 Google Cloud 專案開啟計費才能生成，免費方案對影像模型的額度為 0。
