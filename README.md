# sanchuan-app

三川工方工程管理系統。

## 施工模擬（`simulator.html`）

單一檔案、免安裝，手機瀏覽器直接開。

線上版本：<https://heaven2935-code.github.io/sanchuan-app/simulator.html>

### 怎麼用

1. 右上角「金鑰」貼上 Google Gemini API 金鑰
   （[aistudio.google.com/apikey](https://aistudio.google.com/apikey) 申請，貼上後按「測試」確認）。
   金鑰只存在這台裝置的瀏覽器。
2. **上傳現況照片**
3. **打一句話**說要改成什麼樣子，例「把系統櫃門片換成深胡桃木，霧面不要反光」
4. 需要的話**加一張顏色參考圖**（跟業主看型錄時拍的那張），AI 會照它的顏色與紋理做
5. **開始模擬**

結果會累積在下方，每張標著當初的指令與參考圖。
「下載」與「分享」的圖片下緣會燒上材質名稱與參考圖縮圖，
傳給業主後也分得出哪張是哪個顏色。分享走系統分享，可直接送到 LINE。

### 需要開啟計費

Gemini 影像模型的免費額度為 0，需要在金鑰所屬的 Google Cloud 專案開啟計費。
一張約 NT$1～4，依模型而定。

### 備註

模型不寫死型號：工具會向 API 查詢這把金鑰可用的影像模型並自動挑選，
型號被下架時會自動重挑，不需要改程式。
